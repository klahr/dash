            Keyboard
            
      
            Vim-style. Typing in a field or the terminal is insert mode; Esc (Ctrl-] in the terminal) returns to normal mode.
            
      
            
        
            Move
            hjkl · w/b next/previous lane with todos · gg G · counts like 5j · Ctrl-d/u/f/b scroll
            
        
            Sections
            gt/gT next/previous section · p projects · : command · ? this help
            
        
            Todos
            Enter open · o/a new · e edit · s queue · x stop/cancel · a approve (open todo) · r rework · dd delete · +/- priority · * milestone · t try it · ! shell in worktree
            
        
            Detail
            h/l changes ↔ log · j/k scroll · q/Esc back
            
        
            Search
            / filter the board · Enter jump to first match · n/N next/previous · Esc or :noh clear
            
        
            More
            T run tests again · Y duplicate · E open worktree in editor · u revert a merged todo · O open its pull request · click a diff line to comment · paste or drop images into a todo
            
        
            Approvals
            y allow · A always allow that tool for the todo · n deny
            
        
            Chat
            i type · Enter send · Esc stop typing · j/k scroll
            
        
            Run
            j/k select · Enter view · i type into terminal · x stop · R server · T tests · D deploy · ! shell · / command
            
        
            Forms
            Ctrl-Enter add to queue · Ctrl-s save draft · Esc cancel
            
        
            Commands
            :project name :newproject name [path] :todo … :new :run cmd :push :ci :cleanup :pause :resume :usage :settings :perms :board :chat :activity :clear :noh :notify :q
