                              Runners
                              
      
                              
        
                              
        
      
                              
      
                              
        What is a runner?
        
                              A computer that runs this organization's tasks with dash runner, using its owner's Claude subscription. It connects out to this dashboard, so it needs no open port, VPN or sudo, and adding one takes a single command. Everyone in the organization sees it; its owner and the admins manage it. Link projects to runners in each project's settings.
                              
        
                              This dashboard doesn't run Claude or tasks itself: chats, tasks and scans run on runners, so link each project to one.

                                Keyboard
                                
      
                                Vim-style. Typing in a field or the terminal is insert mode; Esc (Ctrl-] in the terminal) returns to normal mode.
                                
      
                                
        
                                Move
                                hjkl · w/b next/previous lane with tasks · gg G · counts like 5j · Ctrl-d/u/f/b scroll
                                
        
                                Sections
                                gb/gi/gS/gs/gh/gf Board/Issues/Scans/Shell/History/Files · gt/gT next/previous section · o sections, p projects (j/k move, Enter open, Tab other list, Esc back) · J/K next/previous project · c project chat · [ collapse sidebar · F fullscreen on/off · Ctrl-k search projects, tasks and commands, / just tasks · : command · ? this help
                                
        
                                Tasks
                                Enter open (approve in review, enqueue a draft; Space opens) · n (or a) new task · N new task with all options · e edit · s queue · x stop/cancel · z pause/resume · a/Enter approve (task in review) · r rework · dd delete · +/- priority · t live preview (D draws on it: p/a/o/b/c pen/arrow/circle/box/crop, 1–3 colour, x exact capture (desktop Chrome), Ctrl-z undo, Enter add to review, Esc done) · ! shell in worktree
                                
        
                                Detail
                                h/l timeline ↔ changes · j/k scroll · q/Esc back
                                
        
                                More
                                T run tests again · Y duplicate · E open worktree in editor · u revert a merged task · O open its pull request · click a diff line to comment · paste or drop images into a task
                                
        
                                Approvals
                                y allow · A always allow that tool for the task · n deny
                                
        
                                Task chat
                                h/l to the Timeline tab · i type (side chat only; the agent won't see it)
                                
        
                                Chat
                                gc open/close the chat pane · Enter send · Esc stop typing, again to close the overlay · Ctrl-k "Pin chat" keeps it beside the content
                                
        
                                Shell
                                i type into terminal · Ctrl-] leave terminal · x stop · R server · T tests · D deploy · ! new shell
                                
        
                                New task
                                Enter save · Shift-Enter another task · Backspace in an empty field removes it · a pasted text stays one task · Esc close
                                
        
                                Forms
                                Ctrl-Enter add to queue · Ctrl-Shift-Enter/Ctrl-s save draft · Esc cancel
                                
        
                                Commands
                                :project name :newproject name [path] :task … :new :run cmd :shell :push :ci :cleanup :pause :resume :usage :settings :prefs :connector :perms :board :chat :pin :fullscreen :history :clear :noh :notify :vim :list :q
