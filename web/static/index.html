              What is a runner?
              
                                        A computer that runs this organization's tasks with dash runner, using its owner's Claude subscription. It connects out to this dashboard, so it needs no open port, VPN or sudo, and adding one takes a single command. Everyone in the organization sees it; its owner and the admins manage it. Pick a runner on the left to choose the projects it builds, or link runners in each project's settings.
                                        
              
                                        This dashboard doesn't run Claude or tasks itself: chats, tasks and scans run on runners, so link each project to one.

                                          Keyboard
                                          
      
                                          Vim-style. Typing in a field or the terminal is insert mode; Esc (Ctrl-] in the terminal) returns to normal mode.
                                          
      
                                          
        
                                          Move
                                          hjkl · w/b next/previous lane with tasks · gg G · counts like 5j · Ctrl-d/u/f/b scroll
                                          
        
                                          Sections
                                          gb/gi/gS/gs/gh/gf/gl Board/Issues/Scans/Shell/History/Files/Checklist · gt/gT next/previous section · o projects, again for sections (toggles), p projects (j/k move, Enter open, Tab other list, Esc back) · J/K next/previous project · c project chat · [ collapse sidebar · Ctrl-k search projects, tasks and commands, / just tasks · : command · ? this help
                                          
        
                                          Tasks
                                          Enter open (approve in review, or open its pull request when it is reviewed on GitHub; enqueue a draft; Space opens) · n (or a) new task · N new task with all options · e edit · s queue · x stop/cancel · z pause/resume · a/Enter approve (task in review) · r rework · dd delete · +/- priority · _ clear priority · t live preview (D draws on it: p/a/o/b/c pen/arrow/circle/box/crop, 1–3 colour, x exact capture (desktop Chrome), Ctrl-z undo, Enter add to review, Esc done) · ! shell in worktree
                                          
        
                                          Detail
                                          h/l timeline ↔ changes · j/k scroll · q/Esc back
                                          
        
                                          More
                                          T run tests again · Y duplicate · E open worktree in editor · u revert a merged task · O open its pull request · click a diff line (or Tab to its + button and press Enter) to comment · paste or drop images into a task
                                          
        
                                          Approvals
                                          y allow · A always allow that tool for the task · n deny
                                          
        
                                          Task chat
                                          h/l to the Timeline tab · i type (side chat only; the agent won't see it)
                                          
        
                                          Chat
                                          gc open/close the chat pane · Enter send · !command runs a shell command in a project or task chat (no terminal; Claude sees it next turn) · Esc stop typing, again to close the overlay · Ctrl-k "Pin chat" keeps it beside the content
                                          
        
                                          History
                                          j/k (or ↓/↑) select the next/previous commit and show it · gg/G first/last · Ctrl-d/u scroll the commit · q/Esc close it
                                          
        
                                          Checklist
                                          j/k move between items · x/Space check or uncheck · m move to a draft task · M move & queue · +/- move up or down · e edit · dd delete · a add an item · r read TODO.md again (it updates by itself; for hand edits to an untracked one) · changes are committed to TODO.md a moment after the last one
                                          
        
                                          Shell
                                          i type into terminal · Ctrl-] leave terminal · x stop · R server · T tests · D deploy · ! new shell
                                          
        
                                          New task
                                          Enter save · Shift-Enter another task · Backspace in an empty field removes it · a pasted text stays one task · Esc close
                                          
        
                                          Forms
                                          Ctrl-Enter add to queue · Ctrl-Shift-Enter/Ctrl-s save draft · Esc cancel
