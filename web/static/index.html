      Esc
    
          
    
            
              

  
  
    
            
      
            Keyboard
            
      
            Vim-style. Typing in a field or the terminal is insert mode; Esc (Ctrl-] in the terminal) returns to normal mode.
            
      
            
        
            Move
            hjkl · w/b next/previous lane with tasks · gg G · counts like 5j · Ctrl-d/u/f/b scroll
            
        
            Sections
            gb/gs/ga/gh/gf Board/Shell/Activity/History/Files · gt/gT next/previous section · o sections, p projects (j/k move, Enter open, Tab other list, Esc back) · J/K next/previous project · c project chat · [ collapse sidebar · F fullscreen on/off · Ctrl-k search projects, tasks and commands · : command · ? this help
            
        
            Tasks
            Enter open (approve in review, enqueue a draft; Space opens) · a new · e edit · s queue · x stop/cancel · z pause/resume · a/Enter approve (task in review) · r rework · dd delete · +/- priority · t try it · ! shell in worktree
            
        
            Detail
            h/l changes ↔ timeline · j/k scroll · q/Esc back
            
        
            Search
            / filter the board · Enter jump to first match · n/N next/previous · Esc or :noh clear
            
        
            More
            T run tests again · Y duplicate · E open worktree in editor · u revert a merged task · O open its pull request · click a diff line to comment · paste or drop images into a task
            
        
            Approvals
            y allow · A always allow that tool for the task · n deny
            
        
            Task chat
            h/l to the Timeline tab · i type (side chat only; the agent won't see it)
            
        
            Chat
            gc open/close the chat pane · Enter send · Esc stop typing, again to close the overlay · Ctrl-k "Pin chat" keeps it beside the content
            
        
            Shell
            i type into terminal · Ctrl-] leave terminal · x stop · R server · T tests · D deploy · ! new shell
            
        
            Forms
            Ctrl-Enter add to queue · Ctrl-Shift-Enter/Ctrl-s save draft · Esc cancel
            
        
            Commands
            :project name :newproject name [path] :task … :new :run cmd :shell :push :ci :cleanup :pause :resume :usage :settings :prefs :perms :board :chat :pin :fullscreen :activity :history :clear :noh :notify :vim :list :q
